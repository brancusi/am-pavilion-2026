# Localisation (English · Italiano · Հայերեն)

The site is in three languages: English at `/`, Italian at `/it/…`, Armenian (Eastern Armenian,
reformed spelling) at `/hy/…`. Every page exists in all three at the same path after the prefix.

## How it works

- **Library:** FormatJS `intl-messageformat` (ICU MessageFormat), wrapped by `src/amp/i18n.cljs`.
- **Catalogs:** `resources/i18n/<locale>/<domain>.json`, one file per domain (usually one per page)
  in each of `en`, `it`, `hy`. English is the source. `resources/i18n` is on the classpath and the
  JSON is inlined into the page's module at compile time (`defcatalog`), so a page carries its own
  strings and nothing is fetched.
- **Routing:** `amp.services.router` builds every route once per locale (`:locale` in the route data;
  names get a `.it` / `.hy` suffix). The router calls `i18n/set-locale!` before each render and sets
  `<html lang>`. The language switch (`amp.ui.lang-switch`) is in the header, the menu sheet and the footer.
- **Check:** `npm run i18n:check` lists missing or extra keys, ICU errors, `{arguments}`/`<tags>` that
  differ from English, and code using keys English lacks. `--fix` creates missing locale files as `{}`.
- **Browser check:** `node scripts/qa/i18n-snap.mjs <base> <out-dir> <paths…> [--widths 1440,390] [--full]`
  screenshots each path in each locale and reports horizontal overflow, text overflowing its box, and
  i18n console warnings.

## In code

```clojure
(ns amp.pages.visit.page
  (:require [amp.i18n :as i18n :refer [t ts tx] :refer-macros [defcatalog]] …))

(defcatalog "visit")             ; resources/i18n/{en,it,hy}/visit.json; all three files must exist first

(t :visit/hours-title)           ; string (or a React fragment when the message has tags)
(ts :visit/map-alt)              ; always a string: alt, aria-label, title, placeholder, document.title
(t :visit/films {:n 3})          ; "{n, plural, one {# film} other {# films}}"
(t :visit/press-note {:a (i18n/link "/press")})                  ; "<a>Press kit</a>"; internal link, localised
(t :visit/write {:a (i18n/ext-link "mailto:x@y.org")})           ; external / mailto / tel link
(t :visit/k {:b1 (i18n/tag "a" {:href "…" :className "ap-btn"})}) ; any element and props
(i18n/href "/visit")             ; "/it/visit" on Italian pages: EVERY internal href goes through this
(i18n/locale)                    ; "en" | "it" | "hy"
(i18n/t-in "it" :visit/card-title) ; one string in another locale (the driver's card)
(i18n/date "2026-11-18")         ; 18 November 2026 / 18 novembre 2026 / 18 նոյեմբերի 2026 թ.
(i18n/date d {:weekday "long" :day "numeric" :month "long"})
(tx :data-walks "Campo San Polo") ; source-keyed lookup (generated data): translation or the English
(i18n/doc :doc-press-kit)        ; a whole structured JSON document for the locale, English fallback
```

- Look strings up **while rendering** (inside a component or a function it calls), never in a top-level
  `def`: the locale is read when `t` runs. Turn `(def items [...strings...])` into `(defn- items [] ...)` or
  keep keys in the def and call `t` on them when rendering.
- Default tags rendered without a handler: `<em> <strong> <i> <b> <small> <sup> <sub> <q> <cite>`.
  Several links in one message: name them `<a1>`, `<a2>`, … and pass a handler for each.
- `t` returns a string when the message has no tags; with tags, a React fragment. Use `ts` wherever a
  string is required.
- A new JSON file doesn't trigger a recompile: create all three files, then add `defcatalog` (or `touch`
  the .cljs file).

## Catalog files

- `<domain>.json`: flat object, keys in kebab-case grouped with dots by section
  (`"hero.title"`, `"hours.tue-sun"`). Values are ICU messages.
- `data-<name>.json`: **source-keyed**, for text that comes out of generated data (walk plans, press
  image titles and alt text, map labels). The key is the exact English string, the value its translation.
  `en/data-<name>.json` maps each string to itself (the generator, or you, write it). `tx` falls back to
  English when a translation is missing, so a changed source never shows a stale translation.
- `doc-<name>.json`: a structured document (arrays, nested maps, HTML strings) read whole with `i18n/doc`.
- Long HTML content fetched at runtime (Portage sheets, the Armenian-as-well story) is translated as
  whole files: `resources/data/<dir>/<locale>/<sheet>.html` beside the English original, fetched by
  locale with English fallback.

ICU syntax: `{` `}` are argument braces and `<` opens a tag, so write literal ones as `'{'`, `'}'`, `'<'`.
Use typographic apostrophes (’) in prose: a straight `'` before `{` or `}` starts an ICU quote.

## Translation style

- **Voice:** the English is plain, concrete and unhurried, with no marketing gloss. Keep that. Translate
  the meaning, not word by word; keep sentence case; keep the length close (Italian runs ~15% longer,
  Armenian ~20%: check that headings and buttons still fit).
- **Italian:** natural contemporary Italian, the register of a museum or Biennale site. Address the
  reader with *tu* in UI (Pianifica la visita, Iscriviti) and in instructions. Use the Italian names of
  places as Venetians write them (Fondamenta Case Nuove, Campo Santi Giovanni e Paolo). Typographic
  quotes « » in prose, ’ for apostrophes. Existing Italian copy (the press kit `*.it.md`, the water-taxi
  card) shows the house voice: follow its terms (elemento = unit, passeggiata = walk, Tesa 41,
  Padiglione Armenia, studio).
- **Armenian:** Eastern Armenian, reformed orthography, polite plural (*դուք*). Armenian punctuation:
  `։` full stop, `՝` and `,` commas, `«»` quotes, `՞` question mark on the stressed word, `՛` emphasis,
  `—` dashes. Names: Զադիկ Զադիկյան, Արամ Զադիկյան, Թոնի Շաֆրազի, Թինա Չաքարյան, Սվետլանա Սահակյան,
  Ռիչարդ Սերրա, Կոյո Կուո. "Armenian Pavilion" = Հայաստանի տաղավար; the official name = Հայաստանի
  Հանրապետության տաղավար (at the 61st International Art Exhibition – La Biennale di Venezia:
  Վենետիկի բիենալեի 61-րդ միջազգային արվեստի ցուցահանդես). Unit = միավոր, studio = արվեստանոց,
  walk = զբոսանք, plaster = գիպս, pigment = պիգմենտ.
  Place names: in **prose** (journal, essays, story, press releases) transliterate Venetian places
  into Armenian (Վենետիկ, Արսենալե, Սան Մարկո հրապարակ, Մուրանո); in **practical information**
  (addresses, walk stops, directions, maps, hours, the water-taxi card) keep them in Latin as on the
  signs, with Armenian case endings after a hyphen (Tesa 41-ում, Fondamenta Case Nuove-ով).
  "Tesa 41" and "Arsenale Militare" stay in Latin everywhere. Put a word joiner (U+2060) after the
  hyphen of a case ending (`Tesa 41-\u2060ում`) so a line never breaks there; `build/press-kit.mjs`
  adds it to the press kit itself.
- **Never translate:** titles of works, films and the exhibition (*Zadik Zadikian: The Studio*,
  *In Minor Keys*, *Seven Steps to Heaven*, *The Weight of the Flag*: keep them in English, in italics
  where the English has them), "Biennale Arte 2026", names of people and organisations, email
  addresses, phone numbers, URLs. Quotations spoken in English are translated, with the speaker kept.
- **Dates and times:** 24-hour times (10:00–17:30) everywhere. Italian dates "18 novembre 2026";
  Armenian "2026 թ. նոյեմբերի 18" (in a sentence: "նոյեմբերի 18-ին"). Data-driven dates go through
  `i18n/date`.
- Armenian is reviewed by a native speaker before launch; keep the Armenian faithful and plain rather
  than inventive.

## Layout

- Armenian is set in Noto Sans Armenian (the Ayb identity's web face), mixed into each font stack.
  On `/hy/` pages labels, nav and buttons stay in normal case (Armenian capitals tracked wide read
  poorly), and the header keeps the menu sheet below 1280 px. These rules are at the end of
  `resources/css/tailwind.css`; add locale-specific fixes there as `:root[lang="hy"] …` / `:root[lang="it"] …`.
- Check every page you touch at 1440 and 390 (and 1024 for Armenian) in all three languages. Long
  Armenian words in display type are the usual problem: prefer a smaller clamp under `:lang(hy)` to
  breaking words.
