# Armenia Pavilion 2026

The site of the Armenia Pavilion at the Biennale Arte 2026 — *Zadik Zadikian: The Studio* —
live at https://armenianpavilion.org.

ClojureScript (shadow-cljs), helix/React 19 and Tailwind. Each page is its own lazily loaded module.
Images are on Cloudflare R2, films on Mux, the site on Cloudflare Workers.

## Dev

```bash
npm i
npm run dev & npx shadow-cljs watch app     # or the "dev" config in .claude/launch.json
```

Open http://localhost:4200/. Jack in with Calva: shadow-cljs → `:app`.

## Where things are

| Path | What |
|---|---|
| `src/amp/core.cljs` | Entry point. Waits (≤1.2 s) for the fonts before the first render, so text never reflows |
| `src/amp/services/router.cljs` | Routes: `/`, `/artist`, `/armenian-as-well`, `/portage`, `/visit`, `/blog`, `/blog/:slug`, `/press`, `/route-from-hotel-gabrielli`, `/delivery` |
| `src/amp/pages/<page>/` | One folder per page (and shadow-cljs module) |
| `src/amp/ui/` | Shared components: `picture` (R2 images), `fit-gallery`, `video-background` (Mux), `lightbox`, `page-shell`… |
| `src/amp/data/` | Site data: `journal.cljs` (post listings), `films.cljs` (Mux films) |
| `src/amp/pages/blog/posts/` | One namespace per journal post, registered in `blog/registry.cljs` |
| `resources/css/tailwind.css` | Design system (`ap-` classes) |
| `resources/data/press/` | The /press image list, generated by `npm run press` |
| `scripts/media.mjs` | `npm run media -- add <file> <path>`: upload an image to R2 as WebP widths + JPEG |
| `scripts/press.mjs`, `press-sync.sh` | Build /press from the Caption Genius project "Pavilion — Press" |
| `scripts/qa/cls.mjs` | `npm run qa:cls -- [base] [paths…]`: layout-shift sweep of every page (target 0.0000) |
| `scripts/release.clj`, `build/` | Release build |
| `cloudflare/redirect/` | Worker redirecting the old domains to armenianpavilion.org |
| `docs/` | `films.md` (what's in each film), `mockup-viewer.md` (archived 3D viewer), `history/` (old plans) |
| `archive/` | Retired code kept for reference (budget pages) |

## Media

- **Images**: R2 bucket `armenia-pavilion-media`, served at `https://media.armenianpavilion.org/<path>`.
  Cached immutable for a year: to replace an image, upload it under a new key.
- **Films**: Mux, public playback ids in `src/amp/data/films.cljs`.

## Agent skills (`.claude/skills/`)

| Skill | Use |
|---|---|
| `journal-post` | Write a journal post: sources, film stills from the `blackbox` archive, R2 uploads, galleries, zero-shift check |
| `add-media` | Upload a video to Mux and place it |
| `push-to-production` | Commit, release build, deploy to Cloudflare, PR and merge |

## Deployment

Use the `push-to-production` skill, or by hand:

```bash
npx wrangler whoami          # must be the account that owns armenianpavilion.org
npm run release              # builds release/, stamped with the git hash
npx wrangler deploy          # wrangler.jsonc serves release/
```

The redirect Worker only needs `npx wrangler deploy --config cloudflare/redirect/wrangler.jsonc` when
`cloudflare/redirect/` changes. Cache rules live in `resources/misc/_headers`.

Dev output under `public/` (js, css, data, images) and `yarn.lock` change while the dev server runs;
never commit them.
